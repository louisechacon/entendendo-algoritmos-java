# Grafos

Um grafo é um conjunto de conexões. Os grafos são formados por vértices (nós) e arestas (conexões entre os nós), e um vértice pode ser diretamente conectado a muitos outros vértices, por isso os chamamos de vizinhos. A pesquisa em largura é um algoritmo utilizado para percorrer grafos.

## Grafo direcionado (ou dígrafo)

A relação acontece apenas em um sentido.

## Grafo não direcionado (ou simplesmente grafo)

Não contém setas, e ambos os vértices são vizinhos um do outro.
